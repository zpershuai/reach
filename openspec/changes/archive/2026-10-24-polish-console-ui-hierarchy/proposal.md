# Proposal

## Why

上一轮 polish 解决了可达性、焦点和实时链路的问题。这次在线上 Console（桌面 1440/800、手机 375、深色模式）逐页走查后，剩下的主要是信息层级问题：

- 活动表格被未认证的扫描请求（`auth.failed`）占满，客户端一栏还把它们标成 "Gateway"。
- 在线但空闲的设备用灰色显示，和离线很难区分。
- 每一行都有一个实心红色的"撤销身份"按钮。
- 页头和 KPI 在每个页面都重复出现。
- 手机上部分导航标签被截掉，拓扑图只能横向拖动。

这些问题让人一眼判断"系统是否正常、有没有需要我处理的事"变得更难。

## What Changes

**P0：判断与操作安全**

- 未认证请求在活动表格中标为"未认证请求"，不再显示为 "Gateway"，实时事件带有 `count` 合并次数时一并显示（落库记录没有这个字段，本次不加列）。
- 概览和拓扑的活动列表把相邻的同类未认证失败折叠成一行（例如"身份验证失败 ×12 · /unknown"），展开后可以看到每一条。
- 活动页新增"隐藏未认证请求"开关，它和其他筛选一样同步到 URL query，导出时也生效。
- Activity query 新增可选参数 `excludeAuthFailed`。省略时行为不变，传入后服务端分页时排除 `auth.failed` 记录，避免前端过滤造成空页。
- 列表和表格中的破坏性操作（撤销身份、撤销已授权应用、断开客户端）改为描边危险样式，并放在操作组最后。确认弹窗里的提交按钮改为实心危险样式。
- 设备状态配色重定：在线（会话中或空闲）用绿色，连接中或等待心跳用黄色，离线用灰色加虚线。不在会话中的设备，状态胶囊上带相对心跳时间。
- 移动端导航：标签横向滚动时边缘有渐隐提示，当前标签自动滚入视野，不再显示原生滚动条。添加设备按钮保留文字或可见标签。

**P1：信息层级与去重**

- 页头只保留标题、域名和本页操作。版本、健康、心跳间隔、实时连接这些全局状态收进侧栏底部的一个状态块（窄屏时放进导航行）。
- 语言切换统一放在页面右上角：桌面和窄屏都在同一个位置，和页头标题同一行。现在桌面放在左侧栏底部、窄屏放在顶部，位置不一致。主题快捷切换和它并排，组成一个外观控件。侧栏底部不再放语言切换。
- KPI 条固定为 6 / 3 / 2 列网格，不再出现 5+1 折行。"在线设备 4/4"下方用一行小字写"0 台会话中"，不再和数值挤在同一行。为 0 的值弱化显示，错误率或策略拒绝大于 0 时用警告色。拓扑页不再重复 KPI 条。
- 概览的"版本"面板换成"需要关注"面板，列出：离线设备、Engine 版本落后于多数设备、待审核的全局访问客户端、近 24 小时失败或拒绝的请求（不含未认证请求）。没有待处理项时显示"一切正常"，并附 Gateway/MCP 版本这一行。各设备版本只在设备卡片和抽屉中展示。
- 客户端表格：数字列收紧并右对齐；某一列在所有行都为空时隐藏；身份行显示批准时间和最近使用时间，uuid 缩短并配复制按钮；"全局访问"警告从整块底色改为警告胶囊。
- 活动表格列顺序调整为 时间 → 客户端 → 方法 → 结果 → 目标 → 设备 → 耗时/大小。当前页所有行的耗时和大小都为空时隐藏这两列。

**P2：空间利用与细节**

- 设备卡片补充：会话所有者、最近一次操作、工作区数量。设备少于一行时卡片不拉伸到整行。
- 设置页分组为"活动保留""外观""拓扑"三张卡片，表单宽度和其他面板一致。
- Settings 中的语言和主题选项保留，作为完整的偏好入口。
- 技能页仍然是保留状态，导航里的"规划中"标记改为低调样式，不改变要求。
- 窄屏（≤ 820px）的拓扑改为纵向三段：客户端 → Gateway → 设备。选中、筛选、抽屉行为不变，桌面布局不变。**这修改了现有"窄屏横向滚动"的要求。**
- 细节：详情抽屉加半透明遮罩，点击遮罩关闭；修复移动端 KPI 末行多出的边框；客户端头像颜色避开读、写、执行三种语义色。

**不包含**：新依赖、新页面、技能框架、服务端 KPI 口径变更（"需要关注"面板只用快照里已有的字段计算）。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `gateway-console`：修改以下要求：Overview health（"需要关注"面板替代版本面板，KPI 呈现）、Clients view（空列、身份展示）、Topology lanes（窄屏纵向布局替代横向滚动）、Narrow-screen navigation（标签溢出提示）。新增以下要求：未认证请求的展示与折叠、设备状态配色、破坏性操作样式、全局状态位置、活动表格列。
- `gateway-activity-audit`：Activity query 增加可选的 `excludeAuthFailed` 过滤，导出同样适用。
- `console-localization`：Language switching 中"从主导航切换"改为"从每个视口宽度下的页面右上角切换"。

## Impact

- 前端 `packages/gateway-console/`：`App.tsx`、`Views.tsx`、`Activity.tsx`、`AccessClients.tsx`、`Devices.tsx`、`Topology.tsx`、`ui.tsx`、`Glyph.tsx`、`style.css`、`i18n/en.ts`、`i18n/zh-CN.ts` 及对应测试。
- 服务端 `packages/reach-rpc/src/console-api/`：`server.ts` 的 `activityQuery` schema 和 `audit.ts` 的查询与导出各增加一个可选条件，并补测试。API 向后兼容。
- `access-clients` 列表增加批准与最近使用时间，复用现有 OAuth/审计数据，无数据库迁移（实现时确认的范围扩展）。
- 无新增依赖。构建产物仍需通过 `check-build.mjs` 和 CSP 检查。
